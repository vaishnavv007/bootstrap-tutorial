Bootstrap JavaScript APIs

Programmatically control Bootstrap components, configure options, and hook into custom events using vanilla JavaScript.

1. JavaScript Plugins Overview

Bootstrap components can be controlled via HTML data-bs-* attributes, but you can also control them directly with JavaScript. Every plugin is exposed on the global bootstrap object.

Core API Concepts:
  • Instantiation: const modal = new bootstrap.Modal(document.getElementById('myModal'), { options })
  • Methods: modal.show(), modal.hide(), modal.toggle()
  • Events: Listen to component lifecycle events (e.g., element.addEventListener('shown.bs.modal', function() {}))
  • Get Instance: const existingModal = bootstrap.Modal.getInstance(myModalEl)

2. Modal API

Control a modal dialog programmatically without using `data-bs-toggle`.

API Modal
This modal was triggered via JavaScript!

Modal status: Ready

// 1. Initialize
const myModalEl = document.getElementById('apiModal');
const myModal = new bootstrap.Modal(myModalEl, { keyboard: false });

// 2. Call methods
document.getElementById('btnShowModal').addEventListener('click', () => {
    myModal.show();
});

// 3. Listen to events
myModalEl.addEventListener('hidden.bs.modal', event => {
    console.log('Modal was closed!');
});

3. Carousel API

Cycle through carousel items via external JavaScript controls.

const myCarouselElement = document.querySelector('#apiCarousel');
// Initialize with options (e.g., disable auto-sliding)
const carousel = new bootstrap.Carousel(myCarouselElement, {
  interval: false
});

document.getElementById('btnCarNext').addEventListener('click', () => {
    carousel.next(); // Go to next slide
});

document.getElementById('btnCarSlide2').addEventListener('click', () => {
    carousel.to(1); // Index is 0-based
});

4. Tooltip API

Tooltips are opt-in and must be initialized via JavaScript. You can also trigger them manually.

Manual JS Triggers for the above tooltip:
const tooltipEl = document.getElementById('apiTooltip');
const myTooltip = new bootstrap.Tooltip(tooltipEl);

document.getElementById('btnShowTooltip').addEventListener('click', () => {
    myTooltip.show(); 
});

5. Popover API

Like Tooltips, Popovers require JavaScript initialization and can be controlled programmatically.

const popoverEl = document.getElementById('apiPopover');
// Initialize with custom options in JS instead of HTML attributes
const myPopover = new bootstrap.Popover(popoverEl, {
    title: 'Custom JS Title',
    trigger: 'focus' // Dismiss on next click
});

6. Collapse API

Toggle the visibility of content using the Collapse API.

This content is being toggled by a JavaScript event listener calling collapseInstance.toggle(). 
const collapseElementList = document.getElementById('apiCollapse');
const collapseList = new bootstrap.Collapse(collapseElementList, {
  toggle: false // Don't open it immediately on instantiation
});

document.getElementById('btnToggleCollapse').addEventListener('click', () => {
    collapseList.toggle();
});

Toasts are hidden by default. You MUST use JavaScript to show them.

12. 5 Short Answer Questions

  1. What is the difference between `hide.bs.modal` and `hidden.bs.modal` events?
    Answer: `hide.bs.modal` is fired immediately when the hide instance method has been called. `hidden.bs.modal` is fired only after the CSS fading transition has completely finished and the modal is fully hidden.
  2. Explain the purpose of `bootstrap.Modal.getOrCreateInstance(element)`.
    Answer: It safely returns the Bootstrap component instance associated with a DOM element. If the instance doesn't exist yet, it creates a new one and returns it. This avoids creating duplicate instances on the same element.
  3. Why might you pass `{ keyboard: false }` when instantiating a Modal?
    Answer: This configuration option prevents the modal from closing when the user presses the Escape key.
  4. How would you execute code exactly when a Toast disappears?
    Answer: By adding an event listener to the toast element: `element.addEventListener('hidden.bs.toast', () => { /* code */ });`.
  5. If you change a Collapse element's content size dynamically, what might you need to do?
    Answer: Usually nothing, as Collapse handles CSS height transitions natively. But if it's tied to a Scrollspy, you must call the Scrollspy's `.refresh()` method.

14. 2 Mini Projects

Project 1: Chaining Component Events

Goal: Make a Toast appear immediately after a Modal finishes closing.

  • Create HTML for a Modal and a Toast.
  • Initialize both components using JavaScript.
  • Add an event listener to the Modal element listening for the hidden.bs.modal event.
  • Inside the callback function of that listener, call toastInstance.show().

Project 2: Carousel External Controls

Goal: Build a custom UI to control a Carousel.

  • Create a standard Carousel but hide the native prev/next buttons and indicators using CSS (or just omit the HTML for them).
  • Initialize the Carousel in JavaScript with interval: false so it doesn't auto-play.
  • Create a separate HTML list of links (e.g., "View Slide 1", "View Slide 2").
  • Add click event listeners to those links that use the Carousel API .to(index) method to navigate to the specific slide.

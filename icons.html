Bootstrap Icons

Free, high quality, open source icon library with over 2,000 icons. Include them anyway you like—SVGs, SVG sprite, or web fonts.

1. Introduction to Bootstrap Icons

Bootstrap Icons is a dedicated icon library. While they are built for Bootstrap components, they are completely standalone and can be used in any project regardless of whether you use the Bootstrap CSS framework.

Key Features:
  • Over 2,000 icons.
  • Available as SVGs for perfect scaling.
  • Available as an Icon Web Font for rapid prototyping.
  • Inherit the color and size of their parent text automatically.

2. Installation

To use the Web Font approach, you must include the Bootstrap Icons CSS file in your <head>. This is separate from the standard Bootstrap CSS.

<!-- Place this in your <head> to use Bootstrap Icons -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css">

3. Using Icon Fonts

The easiest way to use Bootstrap Icons is via the web font. You add an <i> element with the base class bi, followed by the specific icon class (e.g., bi-alarm).

bi-heart
bi-heart-fill
bi-alarm
bi-gear 
<!-- Example of using the Web Font classes -->
<i class="bi bi-heart"></i>
<i class="bi bi-heart-fill"></i>

4. Using Inline SVGs

For maximum performance and styling flexibility, you can embed the SVG code directly into your HTML. This removes the need for an extra network request (like fetching a font file).

Inline SVG Camera 
<svg xmlns="http://www.w3.org/2000/svg" width="32" height="32" fill="currentColor" class="bi bi-camera" viewBox="0 0 16 16">
  <!-- Path data goes here -->
</svg>

9. 5 Short Answer Questions

  1. What is the difference between `` and ``?
    Answer: `bi-heart` displays the outlined version of the icon, while `bi-heart-fill` displays the solid, filled-in version.
  2. Explain why you can use standard text utilities to style Web Font icons.
    Answer: Because the web font method uses text characters mapped to icon glyphs. The browser treats them as text, so `font-size` and `color` properties apply perfectly.
  3. How would you place a search icon inside an input field?
    Answer: You wrap the `` in an `.input-group` and place the icon inside an `.input-group-text` span attached to the input.
  4. Why is `aria-hidden="true"` important for purely visual icons?
    Answer: It hides the icon from screen readers, preventing them from reading out confusing or redundant character codes to visually impaired users.
  5. What must be included in your HTML `` before you can use the `bi` classes?
    Answer: A `` tag referencing the `bootstrap-icons.min.css` stylesheet from a CDN or local directory.

11. 2 Mini Projects

Project 1: Social Media Footer Toolbar

Goal: Build a horizontal list of social icons using Bootstrap utilities.

  • Create an unstyled inline list (.list-unstyled .d-flex .justify-content-center).
  • Inside the list items, create anchor tags.
  • Inside the anchor tags, place Web Font icons for Facebook, Twitter (X), Instagram, and GitHub (e.g., bi-github).
  • Style the icons using .fs-3 for size and .text-secondary for color.
  • Add a gap between items using .gap-3 on the flex container.

Project 2: Feature Value Props (Cards)

Goal: Use icons as large visual anchors for feature marketing cards.

  • Create a grid row with 3 columns.
  • Inside each column, create a .card with .text-center and heavy padding (.p-4).
  • At the top of the card body, place a very large icon (e.g., .fs-1 .text-primary .mb-3). Use icons like a lightning bolt (Speed), shield (Security), and headset (Support).
  • Below the icon, add a standard .card-title and .card-text.

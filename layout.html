Bootstrap Layout & Structure

Master the foundational elements of Bootstrap 5 layout: Containers, Gutters, Z-index, and the modern CSS Grid.

1. Containers

Containers are the most basic layout element in Bootstrap. They pad the content inside them, and there are three primary types:

  • .container: Sets a max-width at each responsive breakpoint.
  • .container-fluid: Is width: 100% at all breakpoints.
  • .container-{breakpoint}: Is width: 100% until the specified breakpoint.

Visual Demo

.container (Centers and limits width on large screens)
.container-fluid (Always spans full width)
.container-md (100% width until md breakpoint, then sets max-width) 
<div class="container">
  <!-- Content centered with responsive max-widths -->
</div>

<div class="container-fluid">
  <!-- Content spanning full viewport width -->
</div>

2. Gutters

Gutters are the padding between your columns, used to responsively space and align content in the Bootstrap grid system. They use the g-*, gx-*, and gy-* classes (ranging from 0 to 5).

Gutter Types:
.gx-* controls horizontal spacing.
.gy-* controls vertical spacing.
.g-* controls both horizontal and vertical spacing.

4. CSS Grid System (Opt-in)

Bootstrap 5.1 introduced an opt-in CSS Grid layout system. Instead of using .row and .col, you use .grid and .g-col-*.

Why use CSS Grid?
It natively supports 2D layouts (rows AND columns simultaneously), making complex layouts cleaner without deep nesting.

7. 10 Multiple Choice Questions (MCQs)

8. 5 Short Answer Questions

  1. Explain when you would use `.container-sm` instead of `.container`.
    Answer: Use `.container-sm` when you want the element to be 100% width on extra-small screens, but switch to a fixed max-width layout on small screens (576px) and up.
  2. Describe the visual difference between `.gx-5` and `.gy-5`.
    Answer: `.gx-5` adds a large amount of empty space between adjacent columns side-by-side. `.gy-5` adds large space between stacked columns (when they wrap to the next line).
  3. Why must an element have a position applied (e.g., `position-relative`) for `z-3` to work?
    Answer: Standard CSS behavior dictates that `z-index` only affects elements that have a position value other than `static` (like relative, absolute, fixed, or sticky).
  4. What is the advantage of CSS Grid (`.grid`) over Flexbox (`.row`) for complex layouts?
    Answer: CSS Grid natively handles both rows and columns at once, allowing you to easily dictate column spans and start points without nesting multiple `.row` containers.
  5. How does the `.w-100` utility act as a column break?
    Answer: By inserting a div with `.w-100` (which applies `width: 100%`), it forces the flex container to wrap, pushing subsequent columns to the next visual row.

9. 5 Coding Exercises

Exercise 1: Gutter Control

Write a row containing two columns. Make the horizontal gap between them the maximum size (5), and the vertical gap minimum (1).

<div class="row gx-5 gy-1">...</div>
Exercise 2: Responsive Container

Create a container that is full width on mobile and tablets, but snaps to a fixed width on large (lg) desktop screens.

<div class="container-lg">...</div>
Exercise 3: Stacking Elements

Create two absolute positioned divs. Ensure the second div in the HTML appears BEHIND the first div using Bootstrap utilities.

<div class="position-absolute z-2">Front</div>
<div class="position-absolute z-1">Back</div>
Exercise 4: CSS Grid Setup

Using Bootstrap's CSS Grid, create a layout with an element that spans 8 columns, and another that spans 4 columns.

<div class="grid">
  <div class="g-col-8">Main</div>
  <div class="g-col-4">Sidebar</div>
</div>
Exercise 5: The Column Break

In a standard flex `.row`, you have three `.col-4` elements. Write the code to force the 3rd element onto a new line.

<div class="row">
  <div class="col-4">1</div>
  <div class="col-4">2</div>
  <div class="w-100"></div>
  <div class="col-4">3</div>
</div>

10. 2 Mini Projects

Project 1: Image Gallery with Gutters

Goal: Build a seamless, edge-to-edge photo gallery layout.

  • Use a .container-fluid to touch the edges of the screen.
  • Use a .row with .g-0 to remove all gutters (so images touch each other).
  • Create 6 columns (.col-6 .col-md-4).
  • Place a placeholder image inside each column (use w-100 on the img tags).

Project 2: Overlapping Hero Banner

Goal: Create a hero section where a floating text box overlaps an image, utilizing Z-index and Containers.

  • Create an outer wrapper with position-relative.
  • Add a background image or colored div covering 100% width, set to z-0.
  • Inside a .container, create a card/box with text.
  • Apply position-absolute, z-3, and position utilities (like bottom-0 start-50 translate-middle-x) to the card so it floats above the background.

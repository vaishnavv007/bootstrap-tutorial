24. 10 Multiple Choice Questions (MCQs)

25. 5 Short Answer Questions

  1. Explain the basic HTML structure of a Card component.
    Answer: A wrapper div with `.card`, containing optional `.card-img-top`, followed by `.card-body`, which contains `.card-title` and `.card-text`.
  2. Why did Bootstrap 5 drop jQuery for its components?
    Answer: To improve performance, reduce file sizes, and modernize the framework by using vanilla JavaScript features that are now widely supported across modern browsers.
  3. How do you trigger a Toast notification using JavaScript?
    Answer: You select the toast element via DOM, instantiate a new Bootstrap Toast object `new bootstrap.Toast(element)`, and call `.show()` on it.
  4. What is the difference between an Alert and a Badge?
    Answer: Alerts are block-level feedback messages that span the width of their container and can be dismissed. Badges are small, inline labels usually used for counts (like unread messages) or tags.
  5. What is the role of `.navbar-toggler`?
    Answer: It is the button (often displaying a "hamburger" menu icon) that appears on smaller screens to toggle the visibility of the collapsed navbar links.

27. 2 Mini Projects

Project 1: Product Pricing Cards

Goal: Build a 3-tier pricing section using Grid and Cards.

  • Create a container and row with 3 columns (lg-4).
  • Inside each, place a `.card` with `text-center`.
  • In the card-body, add a `.card-title` for the tier (Basic, Pro, Max).
  • Add a display heading (e.g., `.display-4`) for the price.
  • Use a `.list-group.list-group-flush` for the feature list.
  • Place a `.btn.btn-primary.w-100` at the bottom to purchase.

Project 2: Interactive Navbar & Offcanvas

Goal: Build a hybrid navigation system.

  • Create a `.navbar` that expands on `lg` screens.
  • Include a branding logo.
  • Instead of a standard collapse, configure the `.navbar-toggler` button to trigger an `.offcanvas-end` sidebar when clicked on mobile.
  • Place your navigation links inside the Offcanvas body. On desktop, they will appear in the navbar, and on mobile, they slide in from the right.

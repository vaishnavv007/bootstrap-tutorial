Bootstrap Utility API

Learn how to generate, modify, and remove custom utility classes using Bootstrap 5's powerful Sass-based Utility API.

Important Note: Unlike previous modules which relied purely on HTML classes, the Utility API requires Sass (SCSS) compilation. The code snippets in this module demonstrate the Sass code you would write in your custom .scss file before compiling it into your final CSS.

1. Overview of the Utility API

Bootstrap 5 introduced a feature-rich Sass map called $utilities. This map acts as an engine that generates all the utility classes (like .m-3, .text-center, .w-50, etc.) during the Sass compilation process.

Why use it? Instead of writing dozens of custom CSS classes for your specific design system, you simply add rules to the $utilities map. Bootstrap handles generating the standard classes, responsive variations, and pseudo-class states automatically.

2. Anatomy of a Utility

A utility inside the $utilities map is defined by a key (the utility name) and a map of options (properties, values, prefixes).

// Conceptual structure of a utility in Sass
$utilities: (
  "utility-key": (
    property: css-property-name,
    class: css-class-prefix,
    values: (
      class-suffix: css-value
    )
  )
);
  • property: The actual CSS property being changed (e.g., opacity).
  • class: (Optional) The prefix for the generated HTML class. Defaults to the property name if omitted.
  • values: A map or list of values that generate the suffixes (e.g., 50: 0.5 generates .opacity-50).

3. Adding Custom Utilities

To add a brand new utility, you use the Sass map-merge() function to merge your custom definitions into Bootstrap's default $utilities map.

Example: Creating custom cursor utilities.

The code below generates classes like .cursor-pointer, .cursor-wait, and .cursor-not-allowed.

// 1. Import Bootstrap's variables and maps first
@import "bootstrap/scss/functions";
@import "bootstrap/scss/variables";
@import "bootstrap/scss/maps";
@import "bootstrap/scss/utilities";

// 2. Add your custom utility
$utilities: map-merge(
  $utilities,
  (
    "cursor": (
      property: cursor,
      class: cursor,
      values: pointer, wait, not-allowed
    )
  )
);

// 3. Import the rest of Bootstrap
@import "bootstrap/scss/bootstrap";

4. Modifying Existing Utilities

You can override existing utilities by referencing their exact key name in the map. This is perfect for changing the prefix or adding new values to an existing scale.

Example: Adding a new width value to the existing width utilities.

By default, Bootstrap provides .w-25, .w-50, .w-75, and .w-100. Let's add .w-10 and .w-33.

$utilities: map-merge(
  $utilities,
  (
    "width": map-merge(
      map-get($utilities, "width"),
      (
        values: map-merge(
          map-get(map-get($utilities, "width"), "values"),
          (
            10: 10%,
            33: 33.3333%
          )
        )
      )
    )
  )
);

5. Removing Utilities

If you want to keep your final CSS file size small, you can remove utility classes you don't use by setting their key to false or null.

$utilities: map-merge(
  $utilities,
  (
    // Remove the opacity utilities entirely
    "opacity": false,
    // Remove floats
    "float": false
  )
);

6. Responsive Utilities

Bootstrap can automatically generate breakpoint variations (e.g., -sm, -md, -lg) for your custom utility. Just add responsive: true.

$utilities: map-merge(
  $utilities,
  (
    "object-fit": (
      property: object-fit,
      class: obj,
      responsive: true, // Automatically generates .obj-md-cover etc.
      values: (
        contain: contain,
        cover: cover
      )
    )
  )
);

7. State Utilities (Hover / Focus)

Generate pseudo-class variations like :hover or :focus by adding the state key to your utility.

$utilities: map-merge(
  $utilities,
  (
    "opacity": map-merge(
      map-get($utilities, "opacity"),
      (
        state: hover // Generates classes like .opacity-50-hover
      )
    )
  )
);

9. 10 Multiple Choice Questions (MCQs)

10. 5 Short Answer Questions

  1. Briefly describe the relationship between the `property`, `class`, and `values` keys.
    Answer: `property` is the CSS rule being affected (e.g., `width`). `class` is the string prefix for the HTML class (e.g., `w`). `values` are the map of suffixes and CSS values appended to the class (e.g., `50: 50%` creates `.w-50 { width: 50%; }`).
  2. Why is it crucial to import Bootstrap variables and maps *before* modifying the Utility API?
    Answer: Because the `$utilities` map is defined in those initial files. You cannot use `map-merge` on a map that hasn't been instantiated yet.
  3. How would you disable responsive versions of the `margin` utility?
    Answer: You would map-merge into `$utilities`, target the `"margin"` key, and set `responsive: false`.
  4. What is the difference between overriding a Sass variable and modifying the Utility API?
    Answer: Overriding a variable (like `$primary: #000`) changes a value globally across all components. Modifying the Utility API specifically manages the generation of single-purpose CSS utility classes (like `.bg-primary`).
  5. Give one reason why removing unused utilities using `false` is a good practice.
    Answer: It drastically reduces the final compiled CSS file size, improving website load times and performance.

$utilities: map-merge(
  $utilities, ( "width": false )
);
Exercise 2: Create a Z-index Utility

Write a utility that generates .z-index-10 and .z-index-20 with values 10 and 20.

"z-index": (
  property: z-index,
  class: z-index,
  values: (
    10: 10,
    20: 20
  )
)
Exercise 3: Responsive Cursor

Add the property required to make a cursor utility generate responsive classes (e.g., .cursor-md-pointer).

"cursor": (
  property: cursor,
  responsive: true,
  // ... values ...
)
Exercise 4: Hover State Shadow

Write the snippet to add a hover state to the existing shadow utility.

"shadow": map-merge(
  map-get($utilities, "shadow"),
  ( state: hover )
)
Exercise 5: Add a new border radius

Add a new value `xl` to the border-radius utility.

"rounded": map-merge(
  map-get($utilities, "rounded"),
  (
    values: map-merge(
      map-get(map-get($utilities, "rounded"), "values"),
      ( xl: 2rem )
    )
  )
)

Project 1: Text Decoration Extensions

Goal: Add custom text-decoration styles via the Utility API.

  • Set up a SCSS file importing Bootstrap.
  • Target the existing text-decoration utility using map-merge.
  • Add new values to support text-decoration styles like wavy, dashed, and dotted.

Project 2: Filter Utilities Engine

Goal: Build a brand new CSS Filter utility from scratch.

  • Create a new entry in $utilities called "filter".
  • Set the property to filter.
  • Set the class to blur.
  • Set responsive: true.
  • Define values mapping sizes to blur strings (e.g., sm: blur(2px), lg: blur(10px)).
  • Compile the Sass and use .blur-md-lg on an image in your HTML!

The ultimate guide to building responsive layouts using the 12-column flexbox grid.

1. Grid System Overview (12-Column)

Bootstrap’s grid system uses a series of containers, rows, and columns to layout and align content. It’s built with flexbox and is fully responsive. The grid is divided into 12 imaginary columns.

Line-by-line concept:
<div class="container">: Wraps the grid and centers it.
<div class="row">: A horizontal wrapper for columns. Fixes negative margins.
<div class="col-...">: The actual content boxes that take up portions of the 12 columns.

7. Best Practices & Common Mistakes

Best Practices
  • Mobile First: Code for .col- first, then scale up using .col-md-, etc.
  • Container usage: Always place rows inside a .container or .container-fluid.
  • Gutters: Use g-* classes on rows to control spacing between columns.
Common Mistakes
  • Orphan Columns: Placing a .col directly inside a container without a .row (Breaks padding/margins).
  • Over-specifying: Writing col-12 col-sm-12 col-md-12. Just write col-12.
  • Nesting containers: Never put a .container inside another .container.

9. 10 Multiple Choice Questions (MCQs)

10. 5 Short Answer Questions

  1. Explain the purpose of the .row class.
    Answer: It creates a flexbox container for columns and uses negative margins to offset the padding applied to those columns, ensuring neat alignment with container edges.
  2. How do gutters (g-*) work in Bootstrap 5?
    Answer: Gutters control the horizontal (gx) and vertical (gy) gaps between columns. They scale from 0 to 5, mapped to rem utilities.
  3. What is the functional difference between .col and .col-12?
    Answer: .col scales flexibly to share space equally with sibling columns. .col-12 forces the column to span 100% of the row regardless of siblings.
  4. Why must columns be immediate children of a row?
    Answer: Because the grid mathematics rely on the row's negative margins and the flexbox context to align column padding precisely.
  5. Describe how to hide a column on mobile but show it on desktop.
    Answer: Use d-none d-lg-block on the column.

Project 2: Admin Dashboard Layout

Goal: Structure a complex web application interface.

  • Create a top navigation bar (outside the grid or in a 12-col row).
  • Create a sidebar that takes 2 columns on desktop, hidden on mobile (.d-none .d-md-block .col-md-2).
  • Create a main content area taking the remaining 10 columns (.col-12 .col-md-10).
  • Inside the main content area, create a row of 4 KPI cards (use .col-sm-6 .col-lg-3).
Objective: Practice nesting rows inside the 10-column main content area without breaking horizontal scrolling.

5. Blockquotes

Use .blockquote to style standard HTML blockquotes. You can also add a .blockquote-footer for attribution.

<figure>
  <blockquote class="blockquote">
    <p>A well-known quote.</p>
  </blockquote>
  <figcaption class="blockquote-footer">
    Author in <cite>Source Title</cite>
  </figcaption>
</figure>

7. Figures

Use the <figure> tag to display related images and text. Use the classes .figure, .figure-img, and .figure-caption to provide baseline styles.

<figure class="figure">
  <img src="..." class="figure-img img-fluid rounded" alt="...">
  <figcaption class="figure-caption">A caption for the image.</figcaption>
</figure>

11. 5 Short Answer Questions

  1. Explain the difference between .h1 and .display-1.
    Answer: .h1 mimics the default styling (font size and weight) of a standard HTML <h1> tag. .display-1 is a much larger, lighter font-weight class designed for hero sections or highly prominent text.
  2. Why is it recommended to use a <figure> element for blockquotes in Bootstrap 5?
    Answer: Using <figure> allows you to semantically group the quote (<blockquote>) and its attribution (<figcaption>) together neatly, and Bootstrap 5's typography utilities are optimized for this structure.
  3. How do you combine multiple table classes? Give an example.
    Answer: You just add them as a space-separated list inside the class attribute. Example: <table class="table table-striped table-hover table-bordered">.
  4. What CSS properties does .img-fluid apply?
    Answer: It applies max-width: 100%; and height: auto; so the image never overflows its container.
  5. How do you style a description list so the terms and descriptions sit side-by-side?
    Answer: By applying grid classes: .row on the <dl>, and column classes like .col-sm-3 on the <dt> and .col-sm-9 on the <dd>.

13. 2 Mini Projects

Project 1: Author Bio Card

Goal: Combine typography, images, and lists to create a sidebar bio.

  • Use an <img> with .img-thumbnail for the profile picture.
  • Below it, use an <h3> with the author's name.
  • Use a .lead paragraph for a short intro.
  • Use an inline list (.list-inline) for social media text links (Twitter, LinkedIn, GitHub) below the intro.
  • Wrap a favorite quote in a <figure> blockquote structure at the bottom.

Project 2: Data Dashboard View

Goal: Build a mock analytics data table.

  • Create a title using .display-6 reading "Monthly Traffic".
  • Wrap a table in a .table-responsive div.
  • Make the table .table-bordered and .table-hover.
  • Create columns for Month, Visitors, Bounce Rate, and Status.
  • Make the 'Status' cell for one row use .table-danger to indicate a drop in traffic, and another use .table-success to indicate an increase.

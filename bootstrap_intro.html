1. Introduction to Bootstrap

Bootstrap is a free, open-source front-end framework used to build responsive and mobile-first websites quickly. It provides ready-made CSS classes and JavaScript components.

2. Why Bootstrap?

  • Responsive by default
  • Fast UI development
  • Reusable components
  • Cross-browser support
  • Excellent documentation

3. Installing Bootstrap

Three common methods:

  1. CDN
  2. Download files
  3. Package managers (npm)

4. Bootstrap CDN

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>

5. Download Bootstrap

Download compiled CSS/JS or source files from the official Bootstrap website and include them locally.

7. Bootstrap Starter Template

<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <link href="bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <h1 class="text-primary">Hello Bootstrap</h1>
</body>
</html>

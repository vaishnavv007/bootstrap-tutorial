1. Responsive Landing Page

Project Goal: Create a high-converting single-page landing site for an app or service.
Required Components:
  • .navbar.fixed-top for sticky navigation.
  • Hero Section: .container, .display-5, .lead, and dual Call-to-Action .btns.
  • Features: 3-column grid (.col-md-4) with Bootstrap Icons (.bi).
  • Footer: Simple text-center block with copyright.
<!-- Hero Section Skeleton -->
<header class="bg-dark text-white text-center py-5">
    <div class="container px-5">
        <h1 class="display-4 fw-bolder">Welcome to Our Product</h1>
        <p class="lead fw-normal text-white-50 mb-4">Quickly build stunning layouts using Bootstrap 5.</p>
        <a class="btn btn-warning btn-lg px-4 me-sm-3" href="#features">Get Started</a>
        <a class="btn btn-outline-light btn-lg px-4" href="#about">Learn More</a>
    </div>
</header>

<!-- Features Grid Skeleton -->
<section id="features" class="py-5">
    <div class="container">
        <div class="row gx-5">
            <div class="col-lg-4 mb-5">
                <div class="feature bg-warning bg-gradient text-dark rounded-3 mb-3 p-3 d-inline-block">
                    <i class="bi bi-collection fs-3"></i>
                </div>
                <h2 class="h4">Feature One</h2>
                <p>Paragraph of text beneath the heading to explain the heading.</p>
            </div>
            <!-- Repeat col-lg-4 x2 -->
        </div>
    </div>
</section>

8. Blog Layout

Project Goal: A content-focused layout mimicking a traditional news or blog site.
Required Components:
  • Featured Post: A large, full-width .p-4.p-md-5.mb-4.rounded.text-bg-dark block containing a title and excerpt.
  • Main Layout: A `.row` split into `.col-md-8` (Main Content) and `.col-md-4` (Sidebar).
  • Main Content: Multiple blog posts separated by <hr>. Use standard typography (.h2, .text-muted).
  • Sidebar: "About" box (.p-4.bg-light.rounded) and a list of archived links using an unstyled list.

12. 5 Short Answer Questions

  1. In an Admin Dashboard, why use `.container-fluid` instead of `.container`?
    Answer: Dashboards usually contain data-heavy tables and complex grids that require maximum screen real estate. `.container-fluid` uses 100% of the viewport width, whereas `.container` places a max-width limit and adds large margins on wide screens.
  2. Explain the process of creating a "Sticky Sidebar" for a blog.
    Answer: Wrap the sidebar contents in a div with the `.sticky-top` class. To prevent it from hitting the very top edge of the browser, add a top value using inline CSS or custom CSS (e.g., `top: 2rem;`).
  3. How do you ensure a footer always stays at the bottom of the page, even if content is sparse?
    Answer: Make the `` a flex column (`.d-flex .flex-column .min-vh-100`). Then, add `.mt-auto` (margin-top: auto) to the `
    ` element to push it down.
  4. When building a pricing page, why is it recommended to use a row with `.g-4`?
    Answer: `.g-4` applies a consistent gutter (gap) both horizontally and vertically between the pricing cards, ensuring they don't touch each other, especially when they stack vertically on mobile devices.
  5. Describe how to implement a "Dark Mode" toggle in a Bootstrap 5.3 project.
    Answer: Bootstrap 5.3 natively supports color modes. You can toggle dark mode by using JavaScript to change the `data-bs-theme="dark"` attribute on the `` element.

14. Final Project Extensions

Extension 1: Dark Mode Toggle Implementation

Goal: Add a functional theme switcher to your Final Project.

  • Place a button with a moon/sun icon in your .navbar.
  • Write a short vanilla JavaScript function that listens for a click on that button.
  • When clicked, check the current theme by reading the data-bs-theme attribute on the <html> tag.
  • If it's light, change it to data-bs-theme="dark". If dark, change to light.
  • Save the user's preference in localStorage so it persists across page reloads.

Extension 2: Interactive Checkout Offcanvas

Goal: Enhance the E-commerce project by adding a slide-out cart.

  • Change the "Cart" button in your navbar to trigger an .offcanvas.offcanvas-end component.
  • Inside the offcanvas body, use a .list-group.list-group-flush to list out dummy cart items.
  • Each list item should use flexbox (.d-flex.justify-content-between) to align the item name on the left and the price on the right.
  • Pin a Checkout button to the absolute bottom of the offcanvas sidebar.

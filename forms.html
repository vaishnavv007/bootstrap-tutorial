Bootstrap Form Controls

Learn how to build, style, and validate forms using Bootstrap 5's comprehensive set of form control classes.

1. Form Basics, Inputs & Labels

Bootstrap styles textual form controls like <input> and <textarea> with the .form-control class. Labels use the .form-label class. Use margin utilities like .mb-3 to space out form groups.

We'll never share your email with anyone else.
<div class="mb-3">
  <label for="exampleInput" class="form-label">Email address</label>
  <input type="email" class="form-control" id="exampleInput" placeholder="name@example.com">
  <div class="form-text">Helpful text goes here.</div>
</div>

2. Select Menu

Custom <select> menus need only the .form-select class to trigger custom styles.

<select class="form-select" aria-label="Default select">
  <option selected>Open this select menu</option>
  <option value="1">One</option>
</select>

3. Checkboxes & Radio Buttons

Each checkbox or radio button should be wrapped in a .form-check div to ensure proper margins and label alignment. The inputs take .form-check-input and labels take .form-check-label.

Checkboxes
Radio Buttons
<div class="form-check">
  <input class="form-check-input" type="checkbox" id="check1">
  <label class="form-check-label" for="check1">Label</label>
</div>

4. Switches

A switch has the markup of a custom checkbox but uses the .form-switch modifier class on the wrapper to render a toggle switch.

<div class="form-check form-switch">
  <input class="form-check-input" type="checkbox" role="switch" id="switch1">
  <label class="form-check-label" for="switch1">Toggle Switch</label>
</div>

5. Range Slider

Use .form-range on <input type="range"> for consistent cross-browser styling of range inputs.

<label for="range1" class="form-label">Select Volume</label>
<input type="range" class="form-range" id="range1">

6. Input Groups

Easily extend form controls by adding text, buttons, or button groups on either side of textual inputs using .input-group.

  <span class="input-group-text">$</span>
  <input type="text" class="form-control" aria-label="Amount">
  <span class="input-group-text">.00</span>
</div>

7. Floating Labels

Create beautiful, animated floating labels that hover inside the input field. Wrap a pair of <input class="form-control"> and <label> inside a .form-floating container. Note: The <input> must come first, and it must have a placeholder attribute for the CSS to work properly.

Important: The placeholder attribute is required on the input element for the floating animation to trigger via CSS :placeholder-shown pseudo-class, even if you want the placeholder to be invisible. 
<div class="form-floating mb-3">
  <input type="email" class="form-control" id="floatingEmail" placeholder="name@example.com">
  <label for="floatingEmail">Email address</label>
</div>

8. Form Validation

Bootstrap provides styles for valid and invalid form states. Add novalidate to your form, handle the submission with custom JS, and add the .was-validated class to the form. You can also use .is-valid and .is-invalid classes manually.

Bootstrap Forms Complete Code

Copy and paste the code below into your index.html file:

index.html 
<!doctype html>
<html lang="en">

<head>
    <!-- Required meta tags for responsive behavior -->
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">

    <!-- Bootstrap 5 CSS CDN -->
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.0.2/dist/css/bootstrap.min.css" rel="stylesheet"
        integrity="sha384-EVSTQN3/azprG1Anm3QDgpJLIm9Nao0Yz1ztcQTwFspd3yD65VohhpuuCOmLASjC" crossorigin="anonymous">

    <title>Bootstrap Forms Tutorial</title>
</head>

<body>

    <!-- .container adds responsive margins on the sides, .mt-5 adds margin to the top -->
    <div class="container mt-5">
        
        <!-- 
          The <form> wrapper. 
          - needs-validation: Hook for Bootstrap's custom validation JS.
          - novalidate: Stops the browser from showing default, unstyled error popups.
        -->
        <form class="needs-validation" novalidate>

            <!-- ========================================== -->
            <!-- 1. STANDARD TEXT & EMAIL INPUTS            -->
            <!-- ========================================== -->
            <!-- .mb-3 (Margin Bottom 3) provides consistent spacing between form groups -->
            <div class="mb-3">
                <label for="exampleInput" class="form-label">Email address</label>
                <!-- .form-control handles the 100% width, borders, padding, and focus ring -->
                <input type="email" class="form-control" id="exampleInput" placeholder="name@example.com" required>
                <!-- .form-text is used for helper text below an input (shows up small and grey) -->
                <div class="form-text">Enter the official email here.</div>
            </div>

            <!-- ========================================== -->
            <!-- 2. TEXTAREA                                -->
            <!-- ========================================== -->
            <div class="mb-3">
                <label for="exampleTextarea" class="form-label">Message</label>
                <!-- rows="3" dictates the initial height of the box -->
                <textarea class="form-control" id="exampleTextarea" rows="3" placeholder="Enter your message"></textarea>
            </div>

            <!-- ========================================== -->
            <!-- 3. DISABLED INPUT                          -->
            <!-- ========================================== -->
            <div class="mb-3">
                <label for="disabledInput" class="form-label">Disabled input</label>
                <!-- The 'disabled' attribute prevents user interaction. Bootstrap styles it grey automatically. -->
                <input type="text" id="disabledInput" class="form-control" placeholder="Disabled input" disabled>
            </div>

            <!-- ========================================== -->
            <!-- 4. SELECT MENUS (DROPDOWNS)                -->
            <!-- ========================================== -->
            <div class="mb-3">
                <!-- .form-select replaces default browser dropdown styles with a custom arrow -->
                <select class="form-select mb-3" aria-label="Default select example">
                    <option selected>Open this select menu</option>
                    <option value="1">One</option>
                    <option value="2">Two</option>
                    <option value="3">Three</option>
                </select>
            </div>

            <div class="mb-3">
                <!-- .form-select-lg makes the dropdown taller with larger text -->
                <select class="form-select form-select-lg mb-3" aria-label="Large select example">
                    <option selected>Large select (.form-select-lg)</option>
                </select>
            </div>

            <!-- ========================================== -->
            <!-- 5. CHECKBOXES                              -->
            <!-- ========================================== -->
            <div class="mb-3">
                <h5>Checkboxes</h5>
                <!-- .form-check is the wrapper for custom checkboxes -->
                <div class="form-check">
                    <input class="form-check-input" type="checkbox" value="" id="flexCheckDefault">
                    <label class="form-check-label" for="flexCheckDefault">Default checkbox</label>
                </div>
                <div class="form-check mb-4">
                    <!-- The 'checked' attribute makes it selected by default -->
                    <input class="form-check-input" type="checkbox" value="" id="flexCheckChecked" checked>
                    <label class="form-check-label" for="flexCheckChecked">Checked checkbox</label>
                </div>
            </div>

            <!-- ========================================== -->
            <!-- 6. RADIO BUTTONS                           -->
            <!-- ========================================== -->
            <div class="mb-3">
                <h5>Radio Buttons</h5>
                <div class="form-check">
                    <!-- Radio buttons must share the same 'name' attribute (e.g., flexRadioDefault) to act as a group -->
                    <input class="form-check-input" type="radio" name="flexRadioDefault" id="flexRadio1">
                    <label class="form-check-label" for="flexRadio1">Default radio</label>
                </div>
                <div class="form-check">
                    <input class="form-check-input" type="radio" name="flexRadioDefault" id="flexRadio2" checked>
                    <label class="form-check-label" for="flexRadio2">Checked radio</label>
                </div>
            </div>

            <!-- ========================================== -->
            <!-- 7. SWITCHES                                -->
            <!-- ========================================== -->
            <div class="mb-3">
                <!-- Adding .form-switch changes a standard checkbox into a toggle switch -->
                <div class="form-check form-switch">
                    <input class="form-check-input" type="checkbox" role="switch" id="flexSwitchCheckDefault">
                    <label class="form-check-label" for="flexSwitchCheckDefault">Default switch checkbox</label>
                </div>
                <div class="form-check form-switch">
                    <input class="form-check-input" type="checkbox" role="switch" id="flexSwitchCheckChecked" checked>
                    <label class="form-check-label" for="flexSwitchCheckChecked">Checked switch checkbox</label>
                </div>
            </div>

            <!-- ========================================== -->
            <!-- 8. RANGE SLIDER                            -->
            <!-- ========================================== -->
            <div class="mb-3 col-6 offset-3">
                <div class="form-text">Range Slider</div>
                <label for="customRange1" class="form-label">
                    Selected Value: <strong id="sliderValue">50</strong>
                </label>
                <!-- 
                  .form-range styles the track and thumb.
                  oninput(...) is inline JavaScript that updates the <strong> tag above as the slider moves.
                -->
                <input type="range" class="form-range" min="1" max="100" value="50" step="1" id="customRange1"
                    oninput="document.getElementById('sliderValue').innerText = this.value">
            </div>

            <!-- ========================================== -->
            <!-- 9. INPUT GROUPS                            -->
            <!-- ========================================== -->
            <!-- .input-group allows you to attach text or buttons directly to an input -->
            <div class="mb-3 input-group">
                <input type="text" class="form-control" placeholder="Recipient's username" aria-label="Recipient's username">
                <!-- .input-group-text acts as the add-on block -->
                <span class="input-group-text">@example.com</span>
            </div>

            <div class="mb-3 input-group">
                <span class="input-group-text">$</span>
                <input type="text" class="form-control" aria-label="Amount (to the nearest dollar)">
                <span class="input-group-text">.00</span>
            </div>

            <div class="mb-3 input-group">
                <button class="btn btn-outline-secondary" type="button" id="button-addon1">Search</button>
                <input type="text" class="form-control" placeholder="" aria-label="Example text with button addon">
            </div>

            <!-- ========================================== -->
            <!-- 10. FLOATING LABELS                        -->
            <!-- ========================================== -->
            <div class="mb-3">
                <!-- 
                  .form-floating requires the <input> to come FIRST, and the <label> to come SECOND.
                  A placeholder on the input is strictly required for this CSS trick to work!
                -->
                <div class="form-floating mb-3">
                    <input type="email" class="form-control" id="floatingInput" placeholder="name@example.com">
                    <label for="floatingInput">Email address</label>
                </div>
                <div class="form-floating">
                    <input type="password" class="form-control" id="floatingPassword" placeholder="Password">
                    <label for="floatingPassword">Password</label>
                </div>
            </div>

            <!-- ========================================== -->
            <!-- 11. FORM VALIDATION                        -->
            <!-- ========================================== -->
            <section id="validation" class="mb-5 border-top pt-4 mt-4">
                <h2 class="text-primary mb-3">Form Validation</h2>
                <p>Bootstrap provides styles for valid and invalid form states. Try submitting the empty form below.</p>

                <div class="row g-3">
                    <!-- First Name Field -->
                    <div class="col-md-6">
                        <label for="validationCustom01" class="form-label">First name (Required)</label>
                        <input type="text" class="form-control" id="validationCustom01" value="Mark" required>
                        <!-- .valid-feedback displays in green when the input passes validation -->
                        <div class="valid-feedback">Looks good!</div>
                        <!-- .invalid-feedback displays in red when the input fails -->
                        <div class="invalid-feedback">Please enter your first name.</div>
                    </div>

                    <!-- Username Field -->
                    <div class="col-md-6">
                        <label for="validationCustomUsername" class="form-label">Username (Required)</label>
                        <div class="input-group has-validation">
                            <span class="input-group-text" id="inputGroupPrepend">@</span>
                            <input type="text" class="form-control" id="validationCustomUsername" required>
                            <div class="invalid-feedback">Please choose a username.</div>
                        </div>
                    </div>
                </div>

                <!-- Submit Button -->
                <div class="col-12 mt-4">
                    <!-- Clicking this triggers the JavaScript below -->
                    <button class="btn btn-primary" type="submit">Submit and Validate form</button>
                </div>

                <!-- 
                  REQUIRED JAVASCRIPT FOR VALIDATION: 
                  This script intercepts the form submission, checks if inputs with 'required' 
                  are filled, and adds the '.was-validated' class to the form. 
                  Without this, the red/green borders will never appear.
                -->
                <script>
                    (function () {
                        'use strict'
                        // Find all forms with the custom class
                        var forms = document.querySelectorAll('.needs-validation')

                        // Loop over them and apply the validation listener
                        Array.prototype.slice.call(forms).forEach(function (form) {
                            form.addEventListener('submit', function (event) {
                                if (!form.checkValidity()) {
                                    event.preventDefault() // Stop form from reloading the page
                                    event.stopPropagation()
                                }
                                // Add the class that activates the valid/invalid CSS
                                form.classList.add('was-validated')
                            }, false)
                        })
                    })()
                </script>
            </section>

        </form>
    </div>

</body>
</html>

Bootstrap Form Controls

Learn how to build, style, and validate forms using Bootstrap 5's comprehensive set of form control classes.

1. Form Basics, Inputs & Labels

Bootstrap styles textual form controls like <input> and <textarea> with the .form-control class. Labels use the .form-label class. Use margin utilities like .mb-3 to space out form groups.

We'll never share your email with anyone else.
<div class="mb-3">
  <label for="exampleInput" class="form-label">Email address</label>
  <input type="email" class="form-control" id="exampleInput" placeholder="name@example.com">
  <div class="form-text">Helpful text goes here.</div>
</div>

2. Select Menu

Custom <select> menus need only the .form-select class to trigger custom styles.

<select class="form-select" aria-label="Default select">
  <option selected>Open this select menu</option>
  <option value="1">One</option>
</select>

3. Checkboxes & Radio Buttons

Each checkbox or radio button should be wrapped in a .form-check div to ensure proper margins and label alignment. The inputs take .form-check-input and labels take .form-check-label.

Checkboxes
Radio Buttons
<div class="form-check">
  <input class="form-check-input" type="checkbox" id="check1">
  <label class="form-check-label" for="check1">Label</label>
</div>

4. Switches

A switch has the markup of a custom checkbox but uses the .form-switch modifier class on the wrapper to render a toggle switch.

<div class="form-check form-switch">
  <input class="form-check-input" type="checkbox" role="switch" id="switch1">
  <label class="form-check-label" for="switch1">Toggle Switch</label>
</div>

5. Range Slider

Use .form-range on <input type="range"> for consistent cross-browser styling of range inputs.

<label for="range1" class="form-label">Select Volume</label>
<input type="range" class="form-range" id="range1">

6. Input Groups

Easily extend form controls by adding text, buttons, or button groups on either side of textual inputs using .input-group.

7. Floating Labels

Create beautiful, animated floating labels that hover inside the input field. Wrap a pair of <input class="form-control"> and <label> inside a .form-floating container. Note: The <input> must come first, and it must have a placeholder attribute for the CSS to work properly.

Important: The placeholder attribute is required on the input element for the floating animation to trigger via CSS :placeholder-shown pseudo-class, even if you want the placeholder to be invisible. 
<div class="form-floating mb-3">
  <input type="email" class="form-control" id="floatingEmail" placeholder="name@example.com">
  <label for="floatingEmail">Email address</label>
</div>

8. Form Validation

Bootstrap provides styles for valid and invalid form states. Add novalidate to your form, handle the submission with custom JS, and add the .was-validated class to the form. You can also use .is-valid and .is-invalid classes manually.

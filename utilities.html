19. 5 Short Answer Questions

  1. What is the difference between `.w-100` and `.vw-100`?
    Answer: `.w-100` makes the element 100% of the width of its *parent container*. `.vw-100` makes the element 100% of the *viewport* (screen) width, regardless of parent size.
  2. Explain what `.d-md-flex` does.
    Answer: It applies `display: flex;` only on medium screens (≥768px) and larger. On smaller screens, it will revert to its default display behavior unless specified otherwise.
  3. How do you create an absolute centered element over an image?
    Answer: Wrap both in a `.position-relative` container. Apply `.position-absolute .top-50 .start-50 .translate-middle` to the overlay element.
  4. Why did Bootstrap 5 change `.ml` (margin-left) to `.ms` (margin-start)?
    Answer: To support RTL (Right-to-Left) languages natively. "Start" is the left side in English, but the right side in Arabic.
  5. What class would you use to prevent a long URL from breaking the container layout?
    Answer: Use `.text-break` to allow the long string of text to wrap and break properly.

21. 2 Mini Projects

Project 1: Notification Toast UI via Utilities

Goal: Build a custom popup using only utility classes (no component classes).

  • Create a container fixed to the bottom right (.position-fixed .bottom-0 .end-0 .p-3).
  • Inside, create a card-like div using .bg-white .shadow-lg .rounded .border.
  • Make it 250px wide (you can use an inline style or a custom class, as Bootstrap only has % width utilities natively).
  • Inside, use flexbox (.d-flex .justify-content-between .align-items-center .border-bottom .p-2) for a header area.
  • Add a .p-3 .text-muted div for the message body.

Project 2: Feature Callout Block

Goal: Build an attractive marketing block using colors and borders.

  • Create a div with a primary background with 10% opacity (.bg-primary .bg-opacity-10). Note: bg-opacity requires Bootstrap 5.1+.
  • Give it a solid border on the left side only (.border-start .border-primary .border-5).
  • Add heavy padding (.p-5).
  • Inside, use .display-6 .text-primary .fw-bold for a header.
  • Follow it with a .text-dark .fs-5 paragraph.
